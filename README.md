### 3. Mini Compiler with Web IDE

An educational mini compiler built to understand the fundamental stages of compiler construction, with both a command-line interface and a browser-based code editor.

**Technologies:** Python, PLY (Python Lex-Yacc), Flask, HTML, CSS, CodeMirror.

**Key Features:**
- Lexical analysis and tokenization.
- Syntax analysis and Abstract Syntax Tree (AST) generation.
- Semantic analysis and symbol table management.
- Three Address Code (TAC) generation.
- Intermediate code interpretation and execution.
- Integer variable declarations and print statements.
- Arithmetic expressions and operator precedence.
- Lexical and syntax error reporting with line and column information.
- Automated test suite with 12 passing test cases.

🔗 **[GitHub Repository](https://github.com/divy000/Mini-Compiler-Web-IDE)**
